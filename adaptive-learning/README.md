# Iskra Learn — адаптивный учебный прототип

Изолированное демо внутри репозитория сайта школы: `/adaptive-learning/`. Существующая главная страница не заменяется.

## Запуск
Откройте `index.html` через локальный статический сервер. Например: `python -m http.server 8000`, затем откройте `http://localhost:8000/adaptive-learning/`. ES modules могут не работать при открытии через `file://`.

## Настройка
- `src/config.js` — возрастные диапазоны, варианты подачи и feature flags.
- `src/content.js` — предметы, темы, задания, подсказки и объяснения.
- `src/adaptation.js` — простая прозрачная политика смены подачи.
- `src/app.js` — интерфейс и состояние сессии.
- `src/styles.css` — оформление.

## Текущие функции
- Возрастная группа 7–9, 10–12 или 13–16 лет.
- Математика, естествознание и русский язык.
- Три подачи: пример/история, пошагово, схема.
- Ответы на задания, обратная связь, подсказки и счётчик результатов.
- Сброс сессии; прогресс не сохраняется между перезагрузками.

## Безопасность и ограничения
- Нет регистрации, серверного хранения или автоматической обработки аудио.
- Не строит психологические диагнозы и не присваивает тип личности.
- Алгоритм адаптации — демонстрационный, не прошедший научную проверку.
- Перед использованием с реальными детьми необходимы педагогическая проверка контента, тесты, оценка приватности и проверка доступности.
