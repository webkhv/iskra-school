# Iskra Learn — адаптивный учебный прототип

Изолированное демо внутри репозитория школьного сайта: `/adaptive-learning/`. Существующая главная страница не заменяется.

## Запуск

Откройте корень репозитория через локальный статический сервер. Например, из корня проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000/adaptive-learning/`. ES modules могут не работать при открытии через `file://`.

## Проверки

Требуется Node.js 20 или новее. Из папки `adaptive-learning/`:

- `npm test` — запускает unit-тесты контента и логики адаптации.
- `npm run check` — проверяет синтаксис JavaScript и запускает тесты.

Тесты используют встроенный test runner Node.js, дополнительные npm-пакеты не требуются.

## Структура

- `src/config.js` — возрастные диапазоны, варианты подачи и feature flags.
- `src/content.js` — предметы, темы, задания, подсказки и объяснения.
- `src/adaptation.js` — простая прозрачная политика смены подачи.
- `src/app.js` — интерфейс и состояние сессии.
- `src/styles.css` — оформление.
- `tests/` — автоматические проверки структуры уроков и адаптации.
- `docs/PRODUCT.md` — направление самостоятельного приложения для детей и родителей.
- `docs/PRIVACY-AND-SAFETY.md` — требования к приватности и безопасности детей.
- `docs/ROADMAP.md` — этапы разработки и критерии пилота.

## Текущие функции

- Возрастные группы 7–9, 10–12 и 13–16 лет.
- Математика, естествознание и русский язык.
- Три подачи: пример/история, пошагово, схема.
- Ответы на задания, обратная связь, подсказки и счётчик результатов.
- Сброс сессии; прогресс не сохраняется между перезагрузками.

## Безопасность и ограничения

- Нет регистрации, серверного хранения или автоматической обработки аудио.
- Не строит психологические диагнозы и не присваивает тип личности.
- Алгоритм адаптации демонстрационный и не прошёл научную проверку.
- Прототип не готов к публичному промышленному запуску. Перед использованием с реальными детьми необходимы педагогическая проверка контента, тесты, оценка приватности, доступности и безопасности.

## Продуктовый курс

Первый продукт — самостоятельное приложение ребёнка с понятным обзором учебной практики для родителя. Сначала укрепляем учебный цикл и тестируем контент, затем проверяем удобство с семьями. Аккаунты, синхронизацию и серверное хранение добавляем только после отдельного проектирования приватности и доступа.

См. `docs/PRODUCT.md`, `docs/PRIVACY-AND-SAFETY.md` и `docs/ROADMAP.md`.
