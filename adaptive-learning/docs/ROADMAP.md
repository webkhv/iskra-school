# Roadmap

## MVP done
- Responsive browser UI and modular JavaScript.
- Lesson catalogue for three subjects.
- User-selectable explanation format.
- Questions, hints, correctness feedback and session-only summary.
- No voice capture or psychological inference.

## Next
1. Add unit tests for adaptation and content validation.
2. Add a versioned content schema and teacher-facing content editor.
3. Track mastery by specific learning objectives, with confidence and clear provenance.
4. Test learning outcomes against a non-adaptive baseline and delayed recall.
5. Add accounts/server only if needed, with explicit consent, access control, retention limits and deletion workflows.
6. Keep any future AI provider behind a server API; never expose secret keys in browser code.
7. Treat audio as optional and separate: only for voluntarily stated interests, with guardian consent and child assent; do not infer diagnoses, intelligence or personality from voice.

## Acceptance criteria before a school pilot
- Pedagogically reviewed content.
- Automated tests and accessibility checks.
- Clear privacy notice and data deletion process.
- No high-stakes labels or hidden profiling.
- Evidence of learning benefit and subgroup fairness.
